**Sunset 0.1.0.** Speak this next to `/app` if you still run the archive. Do not open `/assets`. Say CRE simulation if DON is `—`.

**0:00–0:20 — Problem**  
Agents can call tools and pay. The log is the model’s word. If it can move money, that is not enough.

**0:20–0:35 — Product**  
Hop is the gate. Private policy. Public settlement. Verifiable evidence. Pay → Decide → Verify. Enterprise: uninsured process without a receipt. Agent: the tool call before the tool call that cannot be undone.

**0:35–2:10 — Live**  
1. `/app`. No API key.  
2. `policy_check`, Aave + Compound. Unpaid → 402.  
3. Pay Hedera exact x402. Watch AGENT BUDGET drop.  
4. Verdict `ALLOW` or `HOLD`. Caps omitted.  
5. VERIFY HASHES. HASHES / SETTLEMENT / CRE SIM. DON stays `—` unless matched.  
6. VERIFY LINK → `/verify/{id}`. HashScan.

Optional 15s: ISSUE passport on Infrastructure, paste token, run again so receipt shows `identity`. Optional `X-Hop-Did` stamps `identity.did` without login.

Optional 10s: 503 path — CRE down, no HashScan (fail closed before settle).

**2:10–2:40 — Infra**  
Graph = public data. CRE = private join (engine, not the product). Hedera = pay rail. HCS = optional stamp. Passport = who. DID = optional audit id. Mandate = spend. Screening field says OFAC not screened. Public HTTP is x402, not OAuth.

**2:40–3:00 — Close**  
Don’t trust the agent. Trust the receipt. CRE is compute. Hop meters the decision.
